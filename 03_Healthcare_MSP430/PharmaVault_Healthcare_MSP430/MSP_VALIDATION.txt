Healthcare station verification, 25 November 2026

Target build
TI MSP430 compiler and linker 21.6.2.LTS compiled main.c and rc522.c for
MSP430F5529. Options included C99, MSP430X small code and small data, O2
and no floating-point printf. Linking used lnk_msp430f5529.cmd, the TI
runtime, 512 bytes reserved for stack and 160 bytes reserved for heap.
The linker and Intel HEX conversion both completed successfully.

The map allocated 2,224 of 8,192 bytes in the RAM region and 16,291 of
48,000 bytes in the main FLASH region. Interrupt vectors are separate
regions. These are linker region sizes for this build.

Host simulation
Ten groups of tests exercised the current C functions using simulated
serial frames, card presence, clocks, LCD feedback and interrupt registers:
  1. Environment frame validation, expiry, recovery and tick rollover.
  2. Pillbox state validation and independent warning freshness.
  3. Test-only overdue display and return to normal test mode.
  4. Seven matching refill replies and 16-character LCD pagination.
  5. Malformed, duplicate and mismatched replies.
  6. Retry, timeout, warning interruption and link loss.
  7. Cancellation while the command queue wraps around.
  8. Card presentation, removal, replacement and queued-tap expiry.
  9. Serial reception and recovery after a receive fault.
 10. A failed refresh preserves the previous complete heading and all
     seven instructions. Each fallback page says "saved"; a later complete
     refresh replaces the entire list.
All ten groups passed. UART interrupts, SPI signals and RF were simulated
or outside the harness. No launch, card read, physical LCD observation or
end-to-end test was performed on the team hardware during this review.
