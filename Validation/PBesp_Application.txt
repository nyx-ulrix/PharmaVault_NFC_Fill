APPLICATION HOST BUILD AND REGRESSIONS
The actual assembled .ino is compiled by Microsoft C++17 with explicit
PvWirelessSerial and PvPillboxSensors test doubles, plus peripheral mocks.
All original weekly and timer-test regressions pass, with the old incoming
ENV acceptance test updated to the new local-sensor authority rule.

- Seven date-specific slots, parking8, once-per-day durable attempts,
  missed-day/late-dose handling, weekly refill lifecycle and saved timer.
- Restart, clock rollback, legacy journal migration, storage corruption and
  injected storage failures retain existing movement lockouts.
- Direct IR tests and timer10s/30s tests, fresh clear/1.5s hold, overdue,
  early/late completion, once-per-test lockout, restart and millis rollover.
- Incoming ENV cannot overwrite local sensor values. Healthcare disconnect
  and reconnect leave local readings and local sensing operational.
- DHT sampling defers during motor stepping or a timed LOW hand hold.
  A completed sample invalidates prior IR observations, preventing an
  unobserved sampling gap from counting toward continuous hand detection.
- Provider ENV and BOX frames are staged every5s. Data age16s uses invalid
  sentinels; disconnect/backpressure cannot replay stale queued sensor data.
- Timer demonstration broadcasts TEST_OVERDUE at30s and TEST after
  completion without inserting real overdue/dose journal entries.
- Instructions enforce auth/token/confirmation, printable ASCII and48
  characters. All93 permitted ASCII bytes round-trip at48-character length
  via MED hexadecimal replies inside the128-byte protocol buffer.
- Commas/semicolons preserve exact text; blank days become Not set.
- Metadata saves preserve active schedule/week/dose state. Reboot retains
  text; failed NVS writes preserve the former stored record and fail closed.
