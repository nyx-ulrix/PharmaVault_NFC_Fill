PHARMAVAULT INDEPENDENT WIRELESS - RELEASE VALIDATION
17 November 2026

This release implements the clarified independent-station architecture:
local sensors/motor/dashboard on PBesp (S3), wireless bridge on ESPmsp
(FireBeetle), remote monitor/NFC/refill pages on healthcare MSP430.

PBesp sketch SHA256: 28949AE7AF036528146112CA7D794BB271B50A30C57D8BEE335A0736717389E9

See Validation/ for detailed evidence from each part:
- Application: actual PBesp firmware state-machine and dashboard tests.
- Wireless transport: actual bridge/transport code with mocked sockets/UART/NVS.
- Sensors: actual vendored DHT pulse decoder and ADC conversion tests.
- Healthcare MSP: strict incoming protocol/refill paging/freshness tests and
  native TI MSP430 compiler21.6.2.LTS build of the supplied .out/.hex.

The original RepeatTimer wired backup is preserved byte-for-byte, including
its MSP firmware and original wiring reference. Shared transport headers and
sensor sources in the sketches match their tested source files. ZIP CRCs,
archive extraction bytes and the SHA256 manifest are checked when packaging.

LIMITS
ESP32 native target compiler probes fail on the authoring PC with Illegal
System DLL Relocation, so no target-built ESP32 binary is supplied or claimed.
Arduino IDE Verify/upload is still required on your PC. Host compilation and
tests do not establish RF range, USB power delivery, actual ADC calibration,
LCD wiring, physical motor travel or pill release. No hardware upload or
live radio test was performed by this process.

The NTC conversion assumes nominal3.3V supply and the supplied10k/B3950 parts.
Demo environment limits are20..30C and<=60%RH, not medicine-specific limits.
The software records step commands, not proof of pill release or ingestion.
NFC opens the single currently paired pillbox; it is not multi-box UID routing.

The PBesp status formatter reuses a global2200-byte buffer; the four original
large stack formatting arrays have been removed. This reduces stack pressure
without changing the normal weekly scheduling/actuation rules. Native stack
usage and real power stability have not been measured.
